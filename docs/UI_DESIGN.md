# 界面实施与验证记录

日期：2026-10-13。视觉基准：`docs/腰椎康复助手界面设计板.png`。

## 1. 本轮实施范围

采用用户提供的设计板，不再沿用上一版暖白 / 青绿主题，也不引入新的桌面框架。保持 Python / PySide6 / SQLite，未修改姿势 reducer、持久化 schema 或提醒服务规则。

- 原生 Windows 标题栏及窗口控制按钮保留；品牌、托盘图标使用本地 SVG。
- 浅蓝左导航、首页选中背景及蓝色指示边、底部植物插画和版本信息。
- 白色状态卡，左侧绿色环形时间刻度和坐姿示意插画，右侧状态、开始时间及主次操作。
- 35 / 40 分钟刻度；环按 `elapsed_seconds / 2400` 顺时针绘制，40 分钟后环保持满刻度，但真实计时继续增加，不清零。该环不是必须坐满的目标。
- 下方三张信息卡：下一提醒倒计时、今日坐姿时长、今日起身次数。
- 35 分钟使用橙色提示；40 分钟使用红色环、状态、起身按钮和保留警示；待处理提醒可逐条确认已读。
- 主要操作高度至少 44 逻辑像素，保留键盘 Space / Tab、焦点样式与可访问名称；秒级刷新不重建按钮，不主动抢焦点。

### 与设计板有意保持的差异

1. 日统计接口尚未实现，后两张信息卡显示“—”和“统计功能尚未开放”，不显示设计图中的 2 小时 15 分和 4 次。
2. 最新授权下，症状、训练、统计、设置及帮助导航均可进入；业务未实现处提供明确占位。登录启动页复用已有托盘适配器。详见 UI_COVERAGE.md。
3. 实际启动询问和中断核实仍在主状态卡内完成。新增独立启动询问样式预览，不产生姿势确认；“不再显示”偏好禁用。未知姿势不启动已确认计时。
4. 使用 PRD 的“我已起身”语义，不把点击按钮视为软件检测到了起身。
5. 最新补齐动作卡、症状表单、统计标签页、完整托盘菜单。动作 / 统计仍为设计占位，未接入真实业务；不把猫牛式、桥式等加入自动执行计划。
6. Windows 系统通知由现有 Qt 托盘适配器交给系统展示，没有自绘或替换 Windows 通知中心；应用内警示不强制弹窗、激活窗口或抢焦点。
7. 插画为本地 SVG 重绘，保持设计板的蓝色品牌、人物和植物视觉语言，不声称像素级复刻整张设计板。

## 2. 状态与时间展示契约

| 状态 | 时间及进度 | 主要操作 |
| --- | --- | --- |
| UNKNOWN | `--:--`；无彩色经过时间环；等待确认 | 现在坐着 / 现在已起身 |
| SITTING | 从现有单调计时服务读经过时间；按 UTC 开始记录转本地时间展示 | 我已起身 / 暂停追踪 |
| UP | `--:--`；等待下一次坐姿确认 | 重新坐下 / 暂停追踪 |
| PAUSED | `--:--`；追踪已暂停，不显示运行倒计时 | 恢复并重新确认 |
| NEEDS_CONFIRMATION | `--:--`；等待核实，不显示确定连续时长 | 一直坐着（自述） / 现在已起身 / 无法确认 |

- 自述继续坐着后：经过时间、环的可访问名称、倒计时及提示均说明为推算，保留“按上次确认推算，可能不准确”。
- 开始时间读取 `state.sitting_since` 并转换到本地时区，不复制设计图日期；中断或不确定时标为“上次坐姿确认于”。
- 倒计时仅显示现有冻结阈值 35 / 40 / 45 / 50 / 55 分钟中尚未经过的下一阈值，不代表系统通知必然已经送达。
- 55 分钟后显示“已达提醒上限”和“无后续定时提醒；起身前保留警示”。不会无限倒计时或增加重复提醒。
- 已读确认不会影响姿势、周期、经过时间或已达到 40 分钟的保留警示。
- 键鼠活动仅作为环境事实；没有任何插画或绿色状态暗示自动姿势识别。

## 3. 布局与实现文件

- 默认窗口 1040 × 780，请求最小尺寸 520 × 540；宽度小于 900 时状态区、操作与信息卡纵向排列。
- 小于 700 时侧栏缩成图标导航；若 Windows 在高 DPI 下强行约束到小于 400，侧栏隐藏，优先保留核心状态和操作。
- 环按可用宽度收缩，长时间文本使用紧凑字号，页面纵向滚动且不产生横向裁切。
- 特别修复祖先布局缓存：环收缩后同步清理状态卡、页面和外壳的最小尺寸缓存。不依赖设置请求最小宽度就能保证可用。
- 自适应布局只在宽度、状态、提醒列表或计时文本长度改变时重排，不在每秒刷新时重复重建页面。

文件：

- `src/rehab_assistant/ui/main_window.py`：主窗口、导航、信息卡、状态绑定与动作反馈。
- `src/rehab_assistant/ui/theme.py`：浅蓝、白、蓝、绿、橙、红语义色与 QSS。
- `src/rehab_assistant/ui/widgets.py`：环形刻度、本地 SVG 渲染、多分辨率线性图标。
- `src/rehab_assistant/ui/assets/`：品牌、坐姿人物、植物三张 SVG。
- `src/rehab_assistant/app.py`：品牌托盘图标；退出时先停止窗口计时器、关闭托盘和 IPC，再关闭服务和数据库。
- `lumbar-rehab-assistant.spec`：补充 SVG 收集规则。未安装 PyInstaller / hatchling，没有运行打包或安装包验证。
- `tests/test_ui.py`、`tests/test_qt_lifecycle.py`：展示契约、核心行为与退出生命周期回归。
- `tools/render_ui_preview.py`、`tools/smoke_windows_ui.py`：隔离数据的截图与启动烟测。

## 5. 剩余问题与验证边界

1. 用户已有的 `adapters/windows/notifications.py` 条件 `threshold_minutes >= 2` 保持不动。这会把 35 分钟通知也显示成“坐姿已达到 40 分钟”。本轮主窗口阈值正确，不能因此宣称系统通知文案已经验收。建议下一步确认是否将该条件恢复为 `>= 40`。
2. 最新页面骨架已补齐，但症状持久化、训练计划、真实统计、完整设置和误操作修正业务仍待后续阶段实现；见 UI_COVERAGE.md。
3. 尚未验证真实锁屏、睡眠恢复、断电、通知被系统抑制、多显示器跨屏 DPI 切换、读屏器、高对比主题及最大系统文字设置。
4. 环的倒计时表现依赖冻结的 V1 提醒阈值；后续若开放配置，应与服务共享阈值契约，不允许只改 UI 文案。
5. SVG 已补入打包配置，但没有构建或运行冻结后的 exe，不宣称安装包资源收集验证通过。
6. 本轮没有提交、推送或部署，也没有改动用户的 `.idea/` 文件。
