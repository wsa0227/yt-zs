# 宇安｜康复资料与记录包 V1

整理日期：2026-10-14。

## 交付边界

10项候选动作、8幅原站图片入口、6组视频入口、2份手册链接。**不包含医院原图、原视频或第三方PDF文件，不是离线媒体包。** 视频仅核对过官方发布页面与链接，未完整播放、逐帧临床审查、字幕核对或目标电脑验收。

慧宇尚无已提供的具体动作医嘱。全部动作为CANDIDATE，已批准动作和有效计划为0。首次安装仍为空，不自动导入或安排训练。

## 文件

- resource_index.html：可搜索的本地资料目录；主动点原站才联网。
- guide.md：完整中文说明、候选动作、图文视频链接、来源与限制。
- catalogue.json：候选内容和媒体索引，供开发适配，非已验收生产导入格式。
- record_templates.json：专业确认、空白计划、日志与待复核安全文案。
- yu_an_review_forms.docx：可编辑或打印的专业确认、单项处方、计划和日志。
- implementation_handoff.md：与现有架构的衔接建议、边界与验收项。
- validation_report.json：资料包结构检查，不代表医学审核或应用实机验收。
- manifest.sha256：交付文件校验值。

解压后打开resource_index.html。专业人员先选择并确认动作、训练量和停止条件，再据实记录许可并人工形成计划。不要把“医院发布的资料”写成“医生已经批准慧宇执行”。

英文与繁体来源保留；中文摘要尚未专业复核。广华医院2011手册只作历史/记录格式参考。模板没有虚构专业人员、处方或训练结果。本次不修改代码、不迁移数据库，不增加自动推荐或自动排程。
