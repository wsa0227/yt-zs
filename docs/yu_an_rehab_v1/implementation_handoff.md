# 宇安｜训练模块开发对接建议

2026-10-14。本包只整理内容和建议字段，未修改代码、建表或执行迁移。

## 1. 已有契约

依据用户提供的《Phase 0 架构决策》第3节：ExerciseCatalog提供save_candidate / approve / suspend / list_executable / record_log；仅APPROVED且未停用项可执行，初始为空，不自动推荐/排程。JournalService的空值不补零；医学文案专业复核后才能发行。

请先核对根目录PRD与真实代码。下列计划和版本字段是本次增补建议，不代表已有功能，不预设迁移版本号。

## 2. 导入与状态

catalogue.json已接入当前应用的用户主动导入流程。首次启动保持空目录。用户主动导入后只能出现CANDIDATE，不能生成APPROVED、有效计划或提醒；重复导入按catalog_id跳过，非法结构和批量写入失败不会留下部分记录。所有patient_prescription、individual_approval_id为空。该验收不等于医学审核或 Windows 实机验收。

来源核对、中文医学文案审核、媒体动作匹配、个人许可、媒体使用权分开存储，不能用一个verified布尔值代替。

## 3. 数据建议

| 逻辑对象 | 需要保存 | 与现有模型关系 |
|---|---|---|
| 来源 | 发布机构、URL、版本/日期、核对状态、限制 | 可先嵌入exercises结构化内容，视实际schema决定 |
| 媒体 | 动作/来源、原URL或本地路径、片段、版本/哈希、语言、权限、审核 | 增补建议，不声称已有 |
| 动作版本 | 名称、摘要、具体变式、内容版本 | 与现有exercises衔接 |
| 个体化许可 | 使用者、动作版本、许可决定、处方、依据、录入人与确认人、复核时间 | 审批字段不足时增补历史记录 |
| 手工计划 | 计划版本、顺序、许可引用、处方快照、整体安排依据 | 新增建议，不加入自动推荐/排程 |
| 日志 | 实際数量、状态、症状前后、停止原因、时间来源、版本快照 | 与exercise_logs衔接 |

不强行要求一次拆出全部表，但不要把关键许可与剂量只写成无法追溯的备注。

## 4. 单机许可边界

区分专业人员直接填写、用户依据书面医嘱代录、口头医嘱自述。软件不核验专业身份，不制造电子签名。只知道“医生允许运动”不能批准具体动作；处方与停止条件不完整保持待核实。

动作审批要绑定版本与变式。计划组合的总量也应有依据。处方修改或停用后，旧日志保留快照，不改写历史。

## 5. 开始训练前的校验

核对动作版本、批准记录、未停用、有效性及必要处方。次数/保持/计时模式区分，不适用字段标注“不适用”。媒体跟练要核对到具体示范或片段；不得审批整张随时变化的播放列表。只有图文的已确认处方不强制配置视频。

新发重要症状触发安全流程，不能靠疼痛低于某分数自动放行。缺失媒体不得随机替换。安全文案仍待专业复核。

## 6. 与姿势、计时分离

开始训练、打开视频、完成日志都不能调用ConfirmUp。看完视频不自动记完成。已起身不等于完成训练；暂停视频不等于PauseTracking。训练模块不得修改35/40分钟阈值或静默清掉待处理提醒。

## 7. 日志与趋势

建议状态为未开始、进行中、用户确认完成、部分完成、因不适中断、跳过。计划外真实活动允许补记，但标SELF_REPORTED_EXTERNAL，不反向批准动作。

未填评分、未确认症状保持null，不能当0或false。计时和用户估计分开；补录不伪造精确秒数。训练前后腰痛/腿痛分别记录，必要时补记延迟反应。每日症状与多条训练日志分别保存。

不自动生成康复率、疗效分或“已好转”结论，不设置连续打卡惩罚。更正与撤销保留历史关联，数据写入成功后再反馈。

## 8. 离线与媒体

HTML目录无外部自动请求；点击原站才联网。未包含第三方原媒体，所有local_path/sha256为空。获得相应许可并确认动作后才允许本地导入。不要绕过平台限制、擅自复制分发或静默替换已确认媒体。

## 9. 验收项目

1. 初次安装仍为空；导入仅产生10项候选，APPROVED为0。
2. 仅来源可靠但个人未确认时，不能开始训练。
3. 泛泛口头许可或缺失必要处方，保持待核实。
4. 版本不匹配、已停用或需复核时，阻止开始并明确原因。
5. 单项获准不自动产生组合计划或训练提醒。
6. 视频结束、关窗与日志保存，不改变姿势状态或自动完成训练。
7. 用户确认完成后事务保存；重复提交幂等。
8. 未填评分保持null，查询和导出不补零。
9. 中断能保存实际量、症状和原因，不要求补足次数。
10. 计划修改后，历史日志仍保留原处方快照。
11. 媒体失效或离线提示明确，不自动下载或替换。
12. 计划外补录不会修改动作许可。
13. 警示症状优先提示停止与就医；低分不能绕过。
14. 点击“知道了提示”不代替必要的专业复核。
15. 备份与导出尊重本地隐私和用户确认，不增加账户/服务器。
16. 分别报告单元、集成、Windows实机测试；资料整理不等于功能完成。

## 10. 给Codex的任务入口

先核对真实训练模块、PRD及schema，以本包作为候选内容和字段草案。只在用户批准范围内实现候选导入、许可记录、停用、真实日志和测试，再评估手工计划。不要改变姿势计时，不增加自动推荐、自动排程、联网模型或未经授权媒体下载。提交修改文件、验证命令、结果及未覆盖边界。
