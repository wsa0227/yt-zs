## 二、占位接口契约

1. `MainWindow.show_page(key)`：只改变当前页面与导航选中状态，不操作姿势服务、不写数据库、不停止提醒。`open_page(key)` 额外显示并激活主窗口，供托盘导航使用。
2. 页面 key 固定为 `home/record/training/chart/settings/info`。宽窗口使用完整导航，紧凑窗口使用图标，OS 约束到小于 400 逻辑像素时使用下拉导航，保证仍有返回入口。
3. `build_pages(window)` 构造展示骨架。症状保存 / 编辑 / 删除 / 导出已接入 service；未接入的统计查询 / 训练启用按钮不可执行且说明原因；不存在“保存成功”的假反馈。
4. 症状默认评分是“未填写”，不是 0 分；“选择 0 分”和“跳过评分”区分。记录按本地日期每日一条持久化，同日保存更新已有记录；缺失日期不会补为 0。
5. 训练库示例名称标记“设计占位”，无来源、审核或计划数据，不能通过任何按钮执行训练。
6. `preview_dialog(window, kind)` 仅展示 startup/warning/limit 样式。不会创建姿势事件、提醒事件或系统通知，不能改变已读状态。
7. `build_tray_menu(window, startup_provider, exit_callback)` 复用人工姿势命令和注入启动适配器。读取 / 写入失败显示实际错误，并恢复实际状态；测试用 Mock、不触碰真实 HKCU。
8. 页面切换不创建新计时器，秒级计时评估仍由既有窗口定时器执行。布局仅在尺寸 / 状态 / 提醒列表等变化及首次显示收尾时重排。
9. 不使用固定尺寸 QStackedWidget 撑大所有页面；隐藏页不参与主布局。嵌套卡 / 标签页缓存由内向外刷新；首次原生显示字体完成后再测量，并同步更新滚动内容尺寸。不通过隐藏横向滚动条来掩盖裁切。

## 三、后续任务与验收

| 次序 | 任务 | 必须测试的验收条件 |
| --- | --- | --- |

| Phase 4C | 今日坐姿与起身统计、7 / 30 天症状趋势 | 跨午夜 / 时区；未知区间与推算统计口径明确；缺失值断点；更正事件重放后统计一致；不自动声称病情好转 |
| Phase 4D | 提醒偏好、启动 / 恢复询问交互、误操作修正 UI、本地数据备份管理 | UI 与服务共用阈值；不能无限提醒；纠正追加事件而非破坏历史；恢复不静默清零；使用一致性数据库备份；删除 / 导出须确认 |
| Phase 5 | 系统事件、故障恢复与资源可靠性 | 真锁屏 / 休眠 / 唤醒、视频播放时空闲、时钟改变、崩溃断电、通知被抑制、重复启动；多显示器 DPI、读屏器、高对比主题 |

每一期独立汇报实际代码变更、测试结果、技术风险和剩余问题；通过确认后再进入下一期。本轮仅同步 Phase 4A 文档状态，不进入 Phase 4B。

## 四、本轮发现并修复的问题

- 隐藏标签页曾保留宽屏行布局最小尺寸，切换到症状页和窄窗口后发生横向溢出。修复卡片 / 标签页由内向外布局刷新，回归用例先访问所有标签再缩窄所有页面。
- 高 DPI 首次显示时字体与滚动区布局请求有一拍差，出现 416 像素宽窗口仍保留 446 像素滚动内容宽度。增加首次显示 / resize 收尾测量及同步内容尺寸。保留无横向滚动断言，不放宽验证要求。
- 小于 400 像素隐藏侧栏后占位页缺乏返回入口；补充下拉页面导航。

## 五、验证边界与待修正事项

- 用户原有 `adapters/windows/notifications.py` 的 `threshold_minutes >= 2` 未改动，会让 35 分钟系统通知使用 40 分钟文案。样式预览正确不代表系统通知文案通过；该差异需优先确认修正。
- 开机问询与 40 分钟独立窗口当前为非业务预览，实际确认 / 警示仍在首页。动作插图、真实来源、训练资料及真实趋势图尚未接入。
- 不能由本轮 UI 回归推出真实休眠 / 锁屏、系统通知可见性、读屏器、跨显示器 DPI 或冻结 exe 已验收。
- 外加 Qt 缩放倍率不等于修改 Windows 设置后的精确 150% / 200% 验收。截图使用固定时钟和内存库，非实际健康数据；症状占位日期读取本地日期。
- 无新增远程资源、业务数据库 schema 或依赖。保留用户 `.idea/` 和已有通知适配器改动。

## 六、本轮实际验证结果（2026-10-14）

- 完整自动化测试：`python -m unittest discover -s tests -p '*.py' -v`，90/90 通过。新增症状领域、service、安全规则和真实 Qt UI 回归；旧页面 / 托盘回归继续保留。
- Windows 原生 UI 复验：页面、托盘和症状 UI 测试均在 Windows 主机执行；完整自动化结果为 90/90。不能将该结果扩大为真实系统通知、锁屏 / 休眠或安装包验收。
- 新增覆盖包括五卡导航、页面切换无数据库写入、隐藏页面仍评估计时 / 提醒、未填写评分与 0 分区分、训练不可执行、统计无假值、预览不改状态、托盘人工操作 / 待核实约束、登录启动同步及读写失败、退出确认。

- 隔离 Windows 启动烟测：`platform=windows visible=True wts_registered=True size=1040x780`，`startup_exit_code=0`。仅证明本次隔离启动窗口可见、WTS 注册及正常退出，不扩大为真实休眠 / 锁屏验收。
- 截图使用内存库与固定时钟，不是用户健康记录；未生成安装包，未提交 / 推送 / 部署。
