## 交付顺序与通过条件

1. **安装编译器并生成安装包（已完成构建）**：本机当前用户安装了 Inno Setup 6.7.3，完整预检和 `tools/build_windows_package.ps1` 通过；输出 `dist/installer/YuAn-Setup-0.1.0.exe`。不要求修改 PATH，支持 `-IsccPath` 显式选择编译器。配置语法已通过实际编译，架构拒绝规则和安装器运行行为仍需目标机验证。
2. **无 Python 目标机启动（待验收）**：在干净 Windows x64 虚拟机或独立测试账户中运行 EXE / 安装包，记录 Windows 版本、文件 SHA-256、首次启动耗时。进入主窗口并核对品牌、提示和首次姿势询问。不要通过删除开发机 Python 模拟干净环境。
3. **页面与资源（待验收）**：逐页打开首页、症状、康复训练、统计、设置、帮助；检查 SVG、图标、图表、中文、空状态与缩放。测试数据只能在独立测试账户或明确隔离目录创建，截图必须注明测试数据。
4. **托盘与单实例（待验收）**：关闭窗口应隐藏到托盘；再次启动同一安装应激活已有实例；托盘退出确认后应释放锁并结束进程。退出后重启仍须确认姿势，不静默延续确定计时。
5. **安装、升级与卸载（待验收）**：验证当前用户安装、快捷方式、覆盖安装与卸载；卸载后保留用户健康数据库和备份。记录测试前后路径和文件摘要，不通过手动删库代替卸载。
6. **登录启动注册（待验收）**：在独立测试账户开启登录启动，核对注册命令指向已安装 EXE；实际注销再登录确认只启动一份；卸载后本应用 Run 值应删除，其他 Run 值保持完整。
7. **真实环境与提醒（待验收）**：按下表逐项记录实际现象。测试期间系统环境变更由人工在测试机执行，自动脚本不锁定或休眠日常使用的工作电脑。
